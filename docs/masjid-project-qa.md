# تحقق مشروع مسجد الإسكان الديني

تمت معاينة صفحة المشاريع ومسار `/projects/27` على سطح المكتب والهاتف. تظهر بطاقة المشروع الجديدة في مقدمة المعرض، وتستخدم اللقطة الخارجية المرفقة غلافًا واضحًا. تعرض صفحة التفاصيل العنوان والمالك والتاريخ والمعرض ذي اللقطات الداخلية والخارجية، ويعمل التخطيط بنظام عمود واحد واضح على الهاتف دون تمرير أفقي.

تُعرض حقول تاريخ الانتهاء والمدة كشرطة طويلة لأن المستخدم قدّم تاريخًا واحدًا فقط، ولا تمثل قيمًا مفترضة عن فترة التنفيذ.
